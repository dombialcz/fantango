# Fantango

A dark-fantasy daily logic game about a thief, a treasury, and a perfectly balanced plan. Fantango generates three deterministic puzzles every day—Easy, Medium, and Hard—using the player's local browser date.

**Play online:** [dombialcz.github.io/fantango](https://dombialcz.github.io/fantango/)

**Play Vaultbound:** [dombialcz.github.io/fantango/dungeon.html](https://dombialcz.github.io/fantango/dungeon.html)

**Learn Vaultbound:** Open `tutorial.html` for a five-lesson guided practice run: recruit a Knight and Ranger, train the Knight, improve the Barracks, use an order and potion, then choose whether to delve deeper or return safely. The optional second floor also lets players practise a confirmed mid-fight escape and see its gold cost. It uses shared game definitions and artwork with separate in-memory practice state, so it never reads or writes campaign saves. Revisit completed lessons or restart at any time. Run `node scripts/check-tutorial.mjs` against a local server to check the full tutorial, keyboard flow, responsive layouts and save isolation.

**Play Mastermind:** [dombialcz.github.io/fantango/mastermind.html](https://dombialcz.github.io/fantango/mastermind.html)

Mastermind has its own cartoon hero portraits and consistent class colors in clues, the picker and guess history: gold Knight, blue Thief, pink Bard, ivory/teal Cleric, red Barbarian, green Ranger and purple Mage. Distinct headgear, faces and class names complement the colors. The responsive layout uses large portraits and readable controls, showing submitted guesses and the current row as the game progresses. Phones place the hero picker above the board. All ten attempts remain available. These assets live in `assets/mastermind/` and do not replace Vaultbound's campaign artwork. See [the portrait prompts](assets/mastermind/ART_PROMPTS.json). Run `node scripts/check-mastermind-art.mjs` against a local server to verify images, colors, guessing and responsive layouts.

Play by filling the 6×6 vault with coins and thieves:

- every row and column contains three of each;
- no three matching symbols can be consecutive;
- `=` means neighboring cells match;
- `×` means neighboring cells differ.

Every published puzzle is checked by two solvers: a backtracking solver proves the solution is unique, and a non-guessing logic solver proves the hint system can explain a path to the answer.

## Run locally

```bash
npm run serve
```

Then open <http://localhost:4173>.

## Test the generator

```bash
npm test
```

The game is plain HTML, CSS, and JavaScript with no runtime dependencies. Generated artwork lives in `assets/` and is optimized for the web.

## Controls

- Click a cell, or use arrow keys and Space, to cycle empty → coin → thief.
- `H` gives an explainable hint.
- `Z` undoes the last mark.
- `R` resets the active heist.
- `1`, `2`, `3` switch difficulty.
- `F` toggles fullscreen.

Fantango is an original implementation inspired by binary logic puzzles. It is not affiliated with LinkedIn.

## Vaultbound

Vaultbound is a second dark-fantasy game in this repository: a ten-day auto-battler dungeon campaign. Inspect heroes on a slot-machine-style contract reel, hire them for free, lock a bench, pay escalating reroll costs, buy level upgrades, and choose after every cleared floor whether to flee with the survivors or continue deeper. Tavern upgrades can roll level 2–5 contracts using progressively halved bonus-level chances; underused-class contracts can reach level 6 once the campaign cap allows it.

The town is a second screen where expedition gold upgrades nine buildings: one for each hero class, plus the Alchemist and Tavern. Every building begins at level 1 and costs 3/6/9/12 gold to reach levels 2–5. Class buildings ask the player to choose one of two permanent-for-the-campaign bonuses at each level. Buildings persist from day to day, then the whole town resets when the ten-day campaign ends. The contract reel remains the core loop: town bonuses shape the heroes it offers rather than replacing recruitment.

Each day starts in town, then moves to preparing the company and entering the dungeon. No contracts are generated until the player explicitly rolls, so Tavern upgrades can improve even the first daily offers. The first roll is free; subsequent rerolls cost 1, 2, 3 gold and so on, resetting each day. Visiting town does not refresh offers or reset prices. The responsive recruitment screen separates the animated contract reel, Hire buttons directly under each offer, the locked active party and reserves, and hero inspection/training controls. A painted town landscape adds grass, cobbled paths, crooked trees, ruined walls, and a distant graveyard without tying the interface to fixed map coordinates. See [the landscape prompt](assets/town/TOWN_LANDSCAPE.md).

Paid actions reuse Fantango's original coin icon and show a prominent PAY price: building upgrades, hero training, and paid rerolls. Mid-battle Flee shows its exact gold loss; safe retreat and free recruitment are labeled FREE. Unaffordable purchases keep readable prices and explain how much more gold is needed. Command points are a separate resource, not gold.

Browser regression checks: `node scripts/check-roster-ui.mjs`, `node scripts/check-battle-ui.mjs`, `node scripts/check-bloodlust.mjs`, and `node scripts/check-gold-ui.mjs` (run a local server first; an optional first argument changes the base URL).

The town uses a responsive HTML/CSS interface with ten illustrated districts and a building inspector (a bottom sheet on phones). The nine upgradeable buildings each have five distinct architectural images: upgrades add rooms, wings, towers, and defenses. The 45 building sprites and seven command paintings are delivered as compressed WebP images. See [art direction and packaging notes](assets/town/ART_DIRECTION.md) and [the complete prompt set](assets/ART_PROMPTS.json).

The tenth district is the Cemetery, a free, non-upgradeable memorial. Its Book of the Fallen records each hero's name, class, final level, day, dungeon floor, campaign, and killer. Every combat death adds one percentage point to the living heroes' maximum-health bonus, including future recruits: 10 graves mean +10%, not compounded +1% steps. This multiplies health after town, building and Bard bonuses. Surviving combatants gain maximum HP immediately but not current HP; dismissed heroes and enemies never count. Records and the bonus persist between days and reset with the ten-day campaign. Its single illustrated sprite was created with built-in image generation; [saved prompt and asset path](assets/town/CEMETERY_ART_PROMPT.json). Run `node scripts/check-cemetery.mjs` against a local server to verify fatal hits, intercepted attacks, bonus stacking, daily persistence, campaign reset, and responsive memorial views.

Mage Guild level determines how many enemies every Mage can hit, while its chosen upgrades add health or speed. Hunter’s Lodge level sets Ranger attack speed, while its upgrades add critical-hit chance or damage. The other districts similarly specialize Knights, Thieves, Bards, Clerics, and Barbarians.

Thieves fight in the front row with 10% base dodge. The Thieves’ Guild's Evasion path adds 5 percentage points of dodge per choice instead of crit; Hollow towns grant them 2 points of dodge as well. Rangers retain their crit upgrades. Knights start with 20% damage reduction, gaining another 5 percentage points per Barracks level above one. A single-target enemy attack aimed at an ally has a 50% chance to be redirected to a randomly chosen living, unfrozen Knight (one roll per attack, no chains); the receiving Knight uses their own dodge and armor. Area attacks cannot be intercepted. Damage reduction, dodge and critical-hit chance are each capped at 90% after stacking all bonuses, including Hold the Line and town defenses. `node scripts/check-hero-defenses.mjs` verifies these rules against a running game.

To encourage varied companies, average deployed class counts across the previous two campaign days determine the least-used classes. All tied classes gain +1 level on new contracts after Tavern rolls (maximum level 5 in the first invasion, 6 thereafter); current heroes are never repeatedly leveled by this rule. Day one has no bonus, and day two uses day one's team. Reserves, hiring and rerolling do not affect popularity. Selection history survives reloads and resets with the campaign; older saves without history start tracking at their next departure. Deploying three or more heroes of one class gives every deployed member of that class a single flat −20% maximum-health and damage penalty, fixed at departure for the whole expedition, even after deaths. Two of a class and reserves are unaffected. Healing, Bard buffs, evasion and speed are unchanged. The roster shows qualifying classes, boosted contract badges, penalty warnings and adjusted health/damage previews. Run `node scripts/check-class-balance.mjs` against a local server for end-to-end verification.

Balance rules are explained at the decision point rather than in a tutorial popup. The reel's Recruitment favour strip shows eligible classes, with an optional two-day average breakdown. Hero inspection explains boosted levels and exact health/damage changes; matching contracts warn before hiring a third of a class. A local recruitment notice links to the party, where the player can reserve heroes; the departure button has a concise penalty reminder. Thief dodge and battle party traits have touch/keyboard-accessible disclosures. Explanations start collapsed, keep their open state through ordinary updates, and never intercept gameplay shortcuts while being operated. Run `node scripts/check-contextual-help.mjs` to verify these flows and four responsive layouts.

During battle, dealing and receiving damage fills a shared Command meter at 0.12 Command per actual damage point (one fifth of the previous rate). All seven illustrated commands are visible from the start in a docked command deck, including their costs, matching hero counts, availability, and active timers. Every class building grants a tactical command, usually scaling with up to four living heroes of its class: Barracks provide Hold the Line, the Thieves’ Guild provides victory-conditional Pilfer, Bard College provides Rally, the Temple provides Divine Aegis, the Fighting Pit provides Bloodlust, Hunter’s Lodge provides targeted Mark Prey, and the Mage Guild provides Time Freeze. Bloodlust costs 60 Command and deals twice the combined attack damage of all living allied frontliners to every enemy in the front row, falling back to the back row if the front is empty. It costs no health; additional Barbarians contribute their own attack damage rather than increasing the multiplier. Commands remain usable while paused. Mark Prey costs 40 Command, focuses a selected enemy and gives reachable attackers +20% attack speed per living Ranger (up to +80%) for ten seconds, ending early if the target dies; Divine Aegis costs 70 Command and shields one chosen hero for eight seconds. Time Freeze costs 100 Command and has a ten-second cooldown after the freeze ends; cooldowns advance only during combat and reset on the next floor. Auto pause at 100 Command can be toggled during battle and starts on for every daily expedition. Resuming at full Command does not immediately pause again. The battle screen uses responsive HTML/CSS formation rows and strike trails, and results leave surviving heroes and their health visible.

The Alchemist stocks each daily expedition with healing potions. Potion appears as the eighth card in the command bar, showing its remaining count and greying out when empty. It costs no Command; press `8` or click the card to choose a wounded hero. Its two-second reuse cooldown follows combat time: pausing freezes it, 2× battle speed advances it twice as fast, and time between fights does not advance it. Levels 1–3 provide one, two, then three potions that restore 20% of maximum health; level 4 keeps three potions and raises healing to 33%, and level 5 raises it to 50%. Each cleared floor also rolls Alchemist level × 10% to restore one potion; choosing the Undead potion legacy adds 50 percentage points (60–100% at levels 1–5) at the current Alchemist healing strength, reported in the floor result and chronicle. Supplies persist between floors but replenish at the beginning of the next day’s expedition. Tavern level—not campaign day—sets contract quality: its five levels provide no bonus roll, then `L2 10%`, `L2 20% → L3 10%`, `L2 30% → L3 15%`, and `L2 40% → L3 20% → L4 10% → L5 5%`.

Enemy health receives a linear +10% per floor on top of existing depth scaling: +10% on floor 1, +50% on floor 5 and +100% on floor 10. This applies to every faction, bosses, escorts and summons, and resets for each new town. Damage and attack intervals use the existing scaling. Existing battles retain their saved health; newly generated enemies use the new values.

The active party grows from four to eight slots over the campaign. Surviving heroes heal after each day, while defeated heroes are lost. Each campaign rolls one of four enemy rosters: Undead Uprising fields skeletons, zombies, bone mages, and necromancers; Demonic Invasion fields cultists, demons, warlocks, and archdemons; the Assassins' Guild fields cutthroats, enforcers, marksmen, and teleporting assassins; and the Orc Warband fields goblins, orcs, goblin archers and orc hexers.

All sixteen campaign enemy types and eight bosses have transparent bust portraits, reused across floors. Undead share violet backlighting, demons warm yellow-orange, and guild enemies and green-skinned orcs crimson. The portraits are lightweight 256px WebPs; names and health remain accessible, and a failed portrait falls back to its original glyph. [Original artwork paths and generation prompts](assets/enemies/ART_PROMPTS.json). Run `node scripts/check-enemy-art.mjs` with a local server to verify portraits, mobile layouts, targeting, freeze, summons, assassin movement, and fallback.

Floor 10 is the victory milestone. Each of the four campaigns has two equally likely bosses, selected on the first floor-10 encounter and retained for the campaign. Demons face the Infernal Dragon or existing Vault Tyrant (row-wide attacks); undead face the Evil Spirit (2-second party freeze every third action) or Lich (random undead summon every second action, capped at 10 living foes); the guild faces the Shadow Assassin (20% evasion and blink strikes) or Guild Master (+25% ally damage / +15% ally speed while alive); the Orc Warband faces the Burning Warlord (heavy front-line strikes) or Elder Shaman (12% maximum-health ally heals). Support bosses bring three faction guards. Boss portraits always retain a gold border, including during damage, freeze and targeting. Their abilities are explained in battle. Defeating the whole encounter immediately concludes the invasion. Floor 11 is inaccessible, and a scheduled event cannot interrupt the ending. Boss art and prompts are in [BOSS_ART_PROMPTS.json](assets/enemies/BOSS_ART_PROMPTS.json). Run `node scripts/check-bosses.mjs` against a local server for the boss regression suite.

Battles have four campaign-specific vertical descent paintings: graveyard/crypts, town/infernal caverns, hidden cellars/guild treasury, and ruined walls/Orc stronghold. Each floor targets another 10% of the image's scrollable travel, easing there over 18 seconds during combat. When a fight ends (including retreat or defeat), the background snaps immediately to that floor's exact depth and stays still on the result screen. Each next floor therefore starts from the previous 10% anchor, even after a quick fight. Floor 10 reaches the bottom and deeper floors stay there. New expeditions restart at town. Pause freezes the scenery; combat speed does not accelerate it. Reduced-motion users see the current floor's static scene. The responsive DOM image uses a clipped compositor transform behind darkened, readable controls; no canvas engine is needed. Only the active campaign's approximately 400 KB WebP is loaded. [Saved artwork and exact built-in generation prompts](assets/battle/ART_PROMPTS.json). `node scripts/check-battle-backdrop.mjs` verifies motion, result snapping, boundaries, pause, reset, accessibility and mobile layouts.

A journey links four different invasions. Winning shows the named boss’s defeat, town, victory day, floor clears, survivors, fallen and chronicle highlights. Before leaving, choose one faction legacy and two surviving veterans (or all survivors if fewer than two). The next faction is chosen randomly from those not yet defeated. Veterans keep names and levels and arrive fully healed; buildings, gold, Cemetery, daily supplies, class-selection history and local floor difficulty reset. Selected legacies stack for the remaining towns: Orcs offer +10% damage or +20% maximum health; Undead offer +50 points of potion recovery or +30 starting Command; Demons offer +5 points of crit or damage reduction; the Guild offers +3 gold every morning or +5 points of evasion. Event starting-Command consequences override the normal 50/80 starting value.

Hero level caps are 5, 6, 7 and 8 across the four invasions. Unlocking a cap does not automatically level anyone. Training still costs current level squared, and surviving expeditions use the active cap. Attack-speed growth from hero levels caps at level 5; power and health continue growing. Recruitment tops out at natural level 5, with underused classes allowed one bonus level up to the active cap and recruitment ceiling of 6. The fourth victory shows the complete journey and offers a combined chronicle download or a fresh journey. Failure after day ten or manually starting a new journey resets its legacies and veteran roster. Older saved victories open the new conclusion automatically. Run `node scripts/check-campaign-journey.mjs` against a local server for full journey, save, progression, reward and responsive checks.

### Mastermind

Mastermind is Vaultbound’s daily hero-code side game. Easy, Medium, and Hard use ordered parties of five, six, and seven classes, each with ten guesses. The party name identifies one triplet, an optional pair, and one exact singleton; class portraits and the decoded clue words remain visible while playing. Feedback reports how many heroes are in the correct position and how many are present in another position. A ten-row board keeps all attempts visible, and the interface can be switched between English and Polish. Daily answers are generated from the browser’s local date and each challenge’s difficulty, with progress saved locally.

Heroes who retreat automatically are guaranteed to gain a level. When the player chooses Flee, each eligible survivor instead has an 80% level-up chance, reduced by 10 percentage points for every other fleeing hero, to a minimum of 0%.

Vaultbound supports mouse, touch, portrait phones, and short landscape screens. Every cleared floor awards gold equal to the current campaign day: 1 gold on day 1 through 10 gold on day 10. You can flee safely between floors, or flee during a battle by sacrificing half your current gold (rounded up). During battle, select a command directly or select Potion and then a wounded hero. Press `1`–`7` to cast commands, `Esc` to cancel targeting, `T` to switch between the contract reel and town, `R` to reroll, `Enter` to begin or continue an expedition, `P` to pause or resume, `Space` to toggle battle speed, and `F` for fullscreen.

Each ten-day campaign receives a random town name: a prefix, settlement, geography, and cosmetic place name. Three traits appear beneath its heading. Prefixes grant small company or starting-gold bonuses; settlements favour a class, provide 1 gold each morning (Estate, including day one), or add one free daily reroll (Crossing). Market makes bard buffs 3% stronger. Geography increases its favoured class’s recruitment weight by 10% relative (about 14.3% → 15.5% with seven classes). Crossing’s extra roll preserves the paid 1g/2g/3g sequence. Names and traits remain fixed until New campaign.

Combat automatically pauses when Command reaches 100. Orders and potions remain usable; Resume or P continues the fight. Resuming at full does not pause again until points have been spent and the meter refills.

The town’s panorama text changes each morning: a new campaign record of cleared floors brings the hopeful daily line; otherwise the bleak line appears. Entering an uncleared floor does not count. A manual retreat with a new record and every departing hero alive gives a clean-retreat line (minimum three heroes). Clearing fewer floors than the previous expedition and losing at least half the departing party gives a costly-setback line (minimum three heroes). Reserves do not affect either condition. Defeating the final boss overrides later setbacks with a hopeful aftermath.

### Expedition events and chronicle

Each campaign pre-generates ten encounters: five general, three specific to its enemy faction, and two guaranteed windfalls. The first appears after 2–5 cumulative floor clears and the others after 2–3 more clears, across day boundaries (re-clearing floor 1 counts again). The encounter screen appears after victory, before Continue/Flee. Each decision reveals its outcome before returning to the floor report. The pool contains 40 uncertain encounters plus a gold cache and an apothecary’s satchel, with 42 small engraved SVG emblems in `assets/events/`.

The cache offers 2–4 gold and +5% attack damage/healing for the rest of the day, or 10–14 gold. The satchel restores two current-expedition healing potions at the Alchemist’s current strength, or sells for 6–9 gold. Both windfalls always succeed. Other compassionate choices have a 66% favourable chance; selfish choices have 34% on hopeful days and 66% on bleak days. Outlook is fixed by the morning text. Exact odds stay hidden; possible consequences are shown before choosing. Injuries are nonlethal. Next-battle consequences survive retreat and expire after that battle; next-day rerolls add to Crossing without changing paid prices, and convert to gold on day ten.

Open **Chronicle** in any screen header to read the campaign by day, including recruitment, upgrades, fallen heroes, cleared floors, retreats, event choices, outcomes and expiring benefits. Download it as Markdown. New campaign preserves the previous adventure; up to five past chronicles remain on this browser. Campaign progress saves locally after actions and regularly during combat; reloading a battle returns paused. An unresolved or resolved event resumes in the same state without rerolling or granting its reward twice.

The complete authored pool is in [VAULTBOUND_EVENTS.md](VAULTBOUND_EVENTS.md). Rebuild the data with `node scripts/build-event-catalogue.mjs` and the vector emblems with `node scripts/build-event-art.mjs`. Browser coverage: `node scripts/check-campaign-events.mjs http://127.0.0.1:4173`.

For the current run’s complete schedule, open **Chronicle → Debug event schedule**, or `event-debug.html` on the same site/browser. The read-only inspector shows all ten selected events, cumulative-clear triggers, progress statuses, saved seed and exact outcome/reward/target rolls. Expand an event for both choices, their possible outcomes and a preview using today’s party/reward values. A viewer-only outlook selector compares hopeful and bleak odds; recorded results stay separate. The inspector refreshes when the game saves in another tab and never writes campaign state. Browser coverage: `node scripts/check-event-debug.mjs http://127.0.0.1:4173`.
